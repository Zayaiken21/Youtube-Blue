2. Relatable setup → escalating complications → a turn → a bigger escalation → one clear, satisfying payoff in the final line or two.
3. Every line is something a person would actually say out loud. Short, punchy turns. Vary rhythm. No speeches longer than 3 sentences.
4. Each character has a distinct voice (word choice, attitude, rhythm) that matches their CHARACTERS description.

Rules for the CHARACTERS section
• One line per speaking character, three parts separated by " | ".

• Descriptions go ONLY here — never in the SCRIPT.

Rules for the SCRIPT section — the parser reads ONLY these lines as speech
• Every line starts with a character NAME in CAPITALS, a colon, a space, then only the words that character says out loud.

• Separate narrator: NARRATOR: words. Only write NARRATOR lines if the narrator actually tells part of the story.
