# Our Voices

Voices people chose to share from Voice Studio. Everything here shows up for everyone under **Our Voices**.

- When someone imports a voice with **Share with everyone** on, the app saves the file for them. Upload it to this folder (GitHub → Add file → Upload files) and it appears for everyone a minute or two later.
- The file name becomes the voice name.
- WAV or MP3, 30 seconds at most. Only add voices the person owns or has permission to share.
