# Preset Voices

Voices you add here show up for everyone in Voice Studio under **Presets**.

- WAV or MP3, 10–20 seconds of clean speech (one speaker, no music or background noise), 30 seconds at most.
- The file name becomes the voice name: `Warm Narrator.wav` shows as "Warm Narrator".
- Add a file (GitHub → Add file → Upload files) and it appears in the app within a minute or two.
- Only add voices you own or have permission to use.
